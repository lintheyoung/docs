# 网关设备 Shadow Schema v1.0

## 基本信息

**设备类型：** `gateway`
**Schema 版本：** `1.0`
**状态：** Active

## 字段定义

### 必填字段 (Required Fields)

#### 基础状态

<ParamField path="connected" type="boolean" required>
  设备连接状态（与 AWS IoT 的 MQTT 连接）
</ParamField>

<ParamField path="timestamp" type="number" required>
  Unix 时间戳（毫秒）
</ParamField>

<ParamField path="gatewayId" type="string" required>
  网关设备 UUID
</ParamField>

<ParamField path="thingName" type="string" required>
  AWS IoT Thing 名称，例如：`IoT-Gateway-000001`
</ParamField>

<ParamField path="status" type="string" required>
  网关工作状态

  **可选值：**
  - `online`: 在线
  - `offline`: 离线
  - `error`: 故障状态
</ParamField>

### 可选字段 (Optional Fields)

<ParamField path="boundDevices" type="array">
  已绑定的子设备列表

  **数组元素：**
  - `deviceId` (string): 子设备 UUID
  - `shadowName` (string): 子设备 Shadow 名称
  - `deviceType` (string): 子设备类型
  - `online` (boolean): 子设备在线状态
</ParamField>

<ParamField path="firmwareVersion" type="string">
  固件版本号，例如：`1.2.0`
</ParamField>

<ParamField path="uptime" type="number">
  设备运行时长（秒）
</ParamField>

<ParamField path="lastAckedReqId" type="string">
  最后确认的命令请求ID
</ParamField>

## 使用说明

### 网关启动流程

1. 网关启动后连接 AWS IoT Core
2. 更新 Shadow reported 状态为 `online`
3. 上报已绑定的子设备列表
4. 开始接收子设备的数据并转发

### 子设备管理

网关的 `boundDevices` 数组包含所有已绑定的子设备信息，App 可以通过订阅网关 Shadow 来获取子设备列表的实时变化。

### 在线检测

- 网关通过 MQTT Keep Alive 机制（30秒）维持连接
- AWS IoT Core 在 45秒（1.5倍 Keep Alive）内无通信时判定离线
- 网关异常断开时，AWS IoT 会自动发布生命周期事件
