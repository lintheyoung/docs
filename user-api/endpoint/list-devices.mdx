## 接口说明

获取当前用户租户下的所有设备信息，包括网关设备和子设备。返回设备的层级关系、状态、类型等详细信息。

## 查询参数

<ParamField query="device_type" type="string">
  按设备类型筛选
  - `gateway`: 仅返回网关设备
  - `smart_trap`: 仅返回智能捕鼠器
  - `vibration_sensor`: 仅返回震动传感器
  - `temp_humidity_sensor`: 仅返回温湿度传感器
  - `pir_sensor`: 仅返回红外传感器
  - 不传则返回所有设备
</ParamField>

<ParamField query="status" type="string">
  按设备状态筛选
  - `registered`: 已注册（工厂创建）
  - `pending`: 待设置（已绑定未完成设置）
  - `active`: 激活（可正常使用）
  - `inactive`: 停用
  - `offline`: 离线
  - 不传则返回所有状态
</ParamField>

<ParamField query="gateway_id" type="string">
  按网关筛选，返回指定网关下的所有子设备

  示例: `d9e3f5c1-4e0a-4b5e-8f3a-1c2d3e4f5a6b`
</ParamField>

<ParamField query="include_shared" type="boolean" default="true">
  是否包含其他用户共享给我的设备
  - `true`: 包含共享设备（默认）
  - `false`: 仅返回自己绑定的设备
</ParamField>

<ParamField query="page" type="number" default="1">
  页码，从1开始
</ParamField>

<ParamField query="limit" type="number" default="20">
  每页数量，范围: 1-100
</ParamField>

## 响应数据

```python Python - 按网关分组显示
import requests
from collections import defaultdict

response = requests.get(
    'https://your-supabase-project.supabase.co/functions/v1/user-devices',
    headers={'Authorization': 'Bearer YOUR_JWT_TOKEN'}
)

devices = response.json()['devices']

# 分组：网关和子设备
gateways = [d for d in devices if d['device_type'] == 'gateway']
children_by_gateway = defaultdict(list)

for device in devices:
    if 'gateway_id' in device:
        children_by_gateway[device['gateway_id']].append(device)

# 显示层级结构
for gateway in gateways:
    status = '🟢 在线' if gateway['online'] else '🔴 离线'
    print(f"\n📡 {gateway['device_nickname']} ({status})")

    children = children_by_gateway.get(gateway['device_id'], [])
    for child in children:
        child_status = '🟢' if child['online'] else '🔴'
        print(f"  {child_status} └─ {child['device_nickname']} ({child['device_type']})")

## 使用说明

### 权限要求
- 需要有效的用户JWT Token
- 返回当前用户租户下的所有设备
- 包含用户自己绑定的设备 + 其他用户共享给自己的设备

### 设备层级关系

返回的设备列表展示了完整的层级关系：

**网关设备字段**：
- `child_count`: 子设备数量
- `child_devices`: 子设备简要信息数组

**子设备字段**：
- `gateway_id`: 所属网关的设备ID
- `gateway_info`: 所属网关的详细信息

      <p>在线: {summary.online_count} | 离线: {summary.offline_count}</p>

      {gateways.map(gateway => (
        <div key={gateway.device_id} className="gateway-card">
          <h3>
            {gateway.online ? '🟢' : '🔴'} {gateway.device_nickname}
          </h3>
          <p>{gateway.child_count} 个子设备</p>

          <div className="child-devices">
            {gateway.child_devices?.map(child => (
              <div key={child.device_id} className="child-device">
                {child.online ? '🟢' : '🔴'} {child.device_nickname}
              </div>
            ))}
          </div>
        </div>
      ))}
    </div>
  );
}
```

  <Accordion title="为什么看不到某些设备？">
    可能的原因：
    1. 设备属于其他租户（不同账号）
    2. 设备尚未绑定到您的账号
    3. 您没有该设备的访问权限
    4. 使用了筛选参数过滤掉了
  </Accordion>

  <Accordion title="child_devices 和单独查询子设备有什么区别？">
    - `child_devices`: 网关对象中内嵌的简要子设备列表，方便快速展示层级
    - 单独查询: 使用 `gateway_id` 参数获取完整的子设备详细信息

    建议：列表页用 `child_devices`，详情页再单独查询
  </Accordion>

  <Accordion title="如何实时更新设备在线状态？">
    **推荐方式**：直接使用后端返回的 `online` 字段，该字段基于 `last_seen` 时间计算（5分钟内有数据则在线）。

    如需实时更新，有两种方式：
    1. **定期刷新**：每30-60秒调用一次此接口
    2. **前端计算**：基于 `last_seen` 字段在前端实时计算在线状态
       ```javascript
       function isOnline(lastSeen) {
         if (!lastSeen) return false;
         const diff = Date.now() - new Date(lastSeen).getTime();
         return diff < 300000; // 5分钟 = 300秒
       }
       ```
    3. **MQTT订阅**（最佳）：订阅设备心跳主题接收实时更新
  </Accordion>

  <Accordion title="设备很多时如何提高加载速度？">
    1. 使用分页: `limit=20` 每页仅加载20个设备
    2. 按需加载: 先加载网关，点击后再加载子设备
    3. 使用筛选: 按 `device_type` 或 `status` 减少返回数据
    4. 启用客户端缓存
  </Accordion>

  <Accordion title="共享设备如何区分？">
    查看 `owner_info.is_me` 字段：
    - `true`: 自己绑定的设备
    - `false`: 其他用户共享给我的设备

    同时 `my_role` 表示您对此设备的权限级别。
  </Accordion>

```javascript
// 使用状态管理（Redux/Zustand）
const useDeviceStore = create((set) => ({
  devices: [],
  summary: {},

  fetchDevices: async (filters) => {
    const params = new URLSearchParams(filters);
    const response = await fetch(`/user-devices?${params}`);
    const data = await response.json();
    set({ devices: data.devices, summary: data.summary });
  },

  updateDeviceStatus: (deviceId, online) => {
    set(state => ({
      devices: state.devices.map(d =>
        d.device_id === deviceId ? { ...d, online } : d
      )
    }));
  }
}));
```
